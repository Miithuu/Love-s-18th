# Happy 18th Birthday, Nandika! ✨🌸

A handcrafted, interactive digital birthday scrapbook and celebration website created with love by Mithun for Nandika's 18th Birthday.

## ✨ Features & Sections

- 🎬 **Cinematic Birthday Intro**: A 3-phase interactive opening story with music box melodies and a personal video theater.
- 📸 **Living Memories Scrapbook**: Aesthetic Polaroid gallery with tapes, stickers, handwritten captions, and lightbox inspection.
- 📱 **Living Memory Reels**: 12 portrait video reels with custom tap controls, interactive playback, sound ducking, and fullscreen cinema mode.
- 🎂 **Birthday Cake & Candles**: Interactive candle blowout simulation with realistic flame extinction and wish reveal.
- 🧠 **Couple's Trivia Quiz**: 5 interactive trivia questions testing how well you know Nandika, with instant feedback and soulmate scoring.
- 🍓 **Treat Catcher Arcade Mini-Game**: Fast-paced arcade game with falling goodies (strawberries, hearts, boba, cakes, golden stars), combos, and a 40,000 pts secret message vault.
- 🔤 **Sweet Word Search**: Interactive crossword/word search puzzle featuring special nicknames and love words with confetti celebrations.
- 🎟️ **Redeemable Birthday Vouchers**: Interactive scratch-off love coupons with live claim status and confetti bursts.
- 💌 **Wax-Sealed Love Letter**: Interactive wax seal opening animation with handwritten love letter, real-time font switcher, and custom love note composer.
- 🎵 **Interactive Vinyl Music Player**: Lo-Fi birthday melody synthesizer, spinning record animation, tone arm physics, and custom audio upload support.
- 💖 **Floating Love Counter**: Interactive quick-reaction love shower button that counts your love and bursts floating hearts across the screen.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Start any local static file server:
   ```bash
   python server.py 8080
   ```
   *Or using standard Python http.server:*
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.

## 🌐 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `nandika-birthday` or `<username>.github.io`).
2. Push all project files to the repository:
   ```bash
   git init
   git add .
   git commit -m "Happy 18th Birthday Nandika! ✨🌸"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings > Pages**.
4. Under **Branch**, select `main` branch and `/ (root)` folder, then click **Save**.
5. Your public website will be live in ~1 minute at `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`!
